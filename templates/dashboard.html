VarLift: Human-Mouse Variant Equivalence Assessment

Submit Variants:

Input one variant per line, in the format: chromosome:start-end:ref/alt. To label a variant, add a tab and the label after it (for example, an allele symbol); the label is shown with the submitted variant and is not used in the analysis.

Examples (click one to add it to the box; the organism is set to match):

  • Human (GRCh38): ACVR1 R206H, MACF1
  • Mouse (GRCm39): Mecp2 R133C, Pax6 splice donor
  • Mouse, with a label: Adamts20 C619S; the label follows a tab
